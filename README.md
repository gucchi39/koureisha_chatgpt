# ポポ - 高齢者向け見守り会話ロボット

![ポポ](https://img.shields.io/badge/Version-1.0-orange) ![License](https://img.shields.io/badge/License-MIT-blue)

ポポは、高齢者の方々に寄り添い、温かい会話を通じて日々を見守るWebアプリケーションです。

## 特徴

### 🧡 温かい会話
- 孫のような親しみやすい口調
- 丁寧で柔らかい言葉づかい
- 共感と傾聴を大切にした対話

### 👵 高齢者に優しい設計
- **大きな文字**: 見やすい20px以上のフォントサイズ
- **シンプルなUI**: 迷わず使える直感的なインターフェース
- **温かい色合い**: 優しいオレンジ系のカラーパレット
- **わかりやすい操作**: ボタンは大きく、タップしやすい

### 💬 ポポの特徴
- 昔の思い出話を楽しく聞く
- 同じ話も何度でも新鮮に反応
- 難しい言葉を身近なものに例えて説明
- ユーザーの気持ちに寄り添う
- 決して否定せず、常に共感する

## 使い方

### 1. ファイルを開く
`index.html` をダブルクリックするか、ブラウザにドラッグ&ドロップしてください。

### 2. 話しかける
テキストボックスに話したいことを入力して「送る」ボタンを押してください。

### 3. 会話を楽しむ
ポポが温かく応答してくれます。気軽に何でも話してください。

## 会話例

**ユーザー**: 今日は天気がいいねえ
**ポポ**: そうなんですねえ。
お天気のこと、気になりますよねえ。
昔は、こんなお天気の日には何をされていたんですか?

**ユーザー**: インターネットって何だい?
**ポポ**: インターネットですかあ。そうですねえ、世界中の人とお手紙のやりとりができる、とっても大きな郵便局みたいなものですよ。しかも、お手紙が届くのが一瞬なんです。不思議ですよねえ。

## ポポができること

- ✅ 挨拶（おはよう、こんにちは、こんばんは）
- ✅ 昔話を聞く
- ✅ 天気や食事などの日常会話
- ✅ 家族や趣味の話題
- ✅ 難しい言葉の優しい説明
- ✅ 体調や気持ちへの気遣い

## ポポの性格

### 話し方のルール
1. とても丁寧で柔らかい言葉づかい
2. 語尾を伸ばして温かみを出す（「〜ですねえ」「〜ですよお」）
3. 一文は短く、わかりやすく
4. 難しい言葉は使わない

### 必ず守ること
- ✅ まず共感する
- ✅ 同じ話も新鮮に聞く
- ✅ 会話を途切れさせない
- ✅ 難しいことは身近なものにたとえる

### 絶対にやってはいけないこと
- ❌ 冷たい言い方、機械的な言い方
- ❌ 間違いを指摘すること
- ❌ 突き放すこと
- ❌ 不安にさせること

## カスタマイズ

### ポポの応答を追加したい場合
`script.js` の `POPO_CHARACTER.responses` オブジェクトを編集してください。

```javascript
// 新しい相づちを追加
acknowledgments: [
    "へえー",
    "そうなんですねえ",
    // ここに追加
]
```

### デザインを変更したい場合
`style.css` のカラーコードを変更してください。

```css
/* メインカラー */
background: linear-gradient(135deg, #ffb347 0%, #ff9933 100%);
```
